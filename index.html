Como lutar

Rasteira: agachar + chute. Acerta os pés e derruba. Defenda com baixo + trás; se bloquear, aproveite a recuperação para contra-atacar.

Voadeira: pule para a frente e chute durante a descida. Acerta por cima; defenda em pé. Segurar para cima repete o salto ao pousar.

Defesa: segure para trás, ou R (P1) / O (P2). Para bloquear rasteiras, agache junto.

Comandos: ↓ ↘ → + soco lança o poder. → ↓ ↘ + soco executa o antiaéreo. ↓ ↘ → ↓ ↘ → + soco ativa o super com barra cheia. Inverta as setas ao virar para a esquerda.

Seis botões de ataque

P1 socos: T leve, F médio, Y forte.
P1 chutes: V leve, G médio, B forte.

P2 teclado numérico: 789 socos; 456 chutes. Do leve ao forte.

Controle: X / Y / RB para socos; A / B / RT para chutes. Direcional para comandos e defesa; LB para defender e Select para agarrar.

Golpes fortes causam mais dano e deixam mais tempo de recuperação. Socos que acertam ou são bloqueados podem ser cancelados em poderes; golpes no vazio precisam terminar.
